CloudShop

Microservices

Cloud-Native E-Commerce Platform

A scalable DevOps project using User, Product, Order, and Notification microservices with Docker, Kubernetes, Jenkins, GitHub Actions, and Render.

Microservices Architecture

User Service

Handles customer registration, login, profiles, and authentication.

Product Service

Manages product catalog, inventory, search, and product details.

Order Service

Processes customer orders, order tracking, and payment coordination.

Notification Service

Sends order confirmations, delivery alerts, and promotional notifications.

DevOps Features

Docker Containerization Kubernetes Deployment CI/CD Automation Git Flow Branching Environment Secrets Cloud Deployment
